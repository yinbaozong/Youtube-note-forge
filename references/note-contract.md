# 中文学习笔记契约

只在字幕与画面计划均成功，且 `extract_frames.py` 已生成非空成功清单后写作。正文不写 `#` 顶层标题，直接从 `## 一句话摘要` 开始。封面图、缩略图、手工复制图片和重复图片不能替代关键帧。

必须按以下顺序保留章节：

1. `## 一句话摘要`
2. `## 核心知识点速览`
3. `## 详细内容总结`
4. `## 重点难点解析`
5. `## 可视化总结`
6. `## 学习图谱`
7. `## 行动建议-举一反三`
8. `## 专业术语表`
9. `## 原始字幕 Transcript`

在撰写前创建画面计划 JSON。每项使用 `section_id`、`timestamp`、`purpose`、`required`；时间点必须来自 SRT，`purpose` 说明这张图将如何帮助理解对应正文段落。只有能够展示步骤、界面、参数、图表、实物、对比或结果的画面才设为必需。

把每张成功抽取的必需图片插入 `## 详细内容总结` 的对应小节，图片前后均需有中文解释。正文图片只能使用 `frame_manifest` 列出的成功关键帧，并且同一图片只能插入一次。正文以中文为主；英文仅限必要术语、产品名、命令、模型、链接和 YAML 字段，并在首次出现时解释。

原始字幕不粘贴到正文。`## 原始字幕 Transcript` 只保留 SRT 链接。完成后运行 `validate_note.py`；第一次失败只编辑当前笔记一次，再次失败立即停下并报告校验项。
