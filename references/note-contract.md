# 中文学习笔记契约

只在字幕与画面计划均成功，且 `extract_frames.py` 已生成非空成功清单后写作。正文不写 `#` 顶层标题，直接从 `## 一句话摘要` 开始。封面图、缩略图和手工复制图片不能替代关键帧。终稿删除“来源状态”“视频描述”“可用视觉素材”“提取警告”“学习笔记整理任务”“输出自检清单”等脚手架，来源信息只保留在 YAML 属性中。

必须按以下顺序保留章节：

1. `## 一句话摘要`
2. `## 核心知识点速览`
3. `## 详细内容总结`
4. `## 重点难点解析`
5. `## 可视化总结`
6. `## 学习图谱`
7. `## 行动建议-举一反三`
8. `## 专业术语表`
9. `## 原始字幕 Transcript`

在撰写前创建同一个计划 JSON，其中包含 `article_outline` 与 `frames`。`article_outline` 根据字幕复杂度生成 3-8 个章节，每项包含 `section_id`、`title`、`start`、`end`、`core_claims` 和 `learning_goal`。截图按学习价值选择：每个确有视觉证据的章节通常安排 1 张必需图，独立步骤、参数、对比或结果可增加可选图；大多数视频使用 6-14 张，24 张只是硬安全上限而不是目标。不要为凑数量规划多个几乎相同的时间点。`frames` 每项使用 `section_id`、`timestamp`、`purpose`、`required`；时间点必须来自 SRT，`purpose` 说明这张图将如何帮助理解对应正文段落。只有能够展示步骤、界面、参数、图表、实物、对比或结果的画面才设为必需。

`## 详细内容总结` 必须使用每个 `article_outline.title` 作为完全一致的 `###` 标题。每章解释核心论点、视频中的依据或案例，以及这部分对学习者的意义。把每张成功抽取的必需图片插入对应章节，图片前后均需有中文解释。正文图片只能使用 `frame_manifest` 列出的成功关键帧，并且同一图片只能插入一次。相似的终端、代码、幻灯片和界面状态仍然保留，不做 OCR、AI 识别或感知去重，只过滤近乎纯黑或纯白的空白帧。正文内容由字幕决定，图片只作辅助证据，不能因为图片数量改变文章深度。正文以中文为主；英文仅限必要术语、产品名、命令、模型、链接和 YAML 字段，并在首次出现时解释。

详细总结的最低深度按视频时长动态校验，并检查章节数量、每章有效中文、重复长段落和行动建议。YAML 写入 `skill_version: 3.4.0` 与 `quality_profile_version: 1`。原始字幕不粘贴到正文。`## 原始字幕 Transcript` 只保留 SRT 链接。完成后运行 `validate_note.py`；第一次失败只编辑当前笔记一次，不得重新提取字幕或截图，再次失败立即停下并报告校验项。
